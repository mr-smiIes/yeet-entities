# Yeet Entities

Fabric 1.20.4 mod.

## Controls
- Shift + Left Click an entity: grab it into your right hand.
- Right Click: launch the held entity at high speed.
- Hitting a block destroys the thrown entity.
- Hitting another entity kills the target and the thrown entity.

## Config
On first launch the mod creates `config/yeet_entities.json`.

Settings include throw speed, pickup range, whether players can be grabbed, block/entity impact behavior, gravity, sounds, and impact particles.

## Requirements
- Minecraft 1.20.4
- Fabric Loader 0.15+
- Fabric API 0.97.3+1.20.4
- Java 17+
